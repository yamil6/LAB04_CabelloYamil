# Visual Studio Code

## 1. Introducción

### 1.1 ¿Qué es la herramienta?
Visual Studio Code es un editor de código fuente ligero gratis. Utilizado por los programadores para escribir, editar, correr y depurar código.

### 1.2 ¿Para qué se utiliza?
Se puede utilizar Visual Studio Code para:
- Escribir y modificar código.
- Encontrar y depurar errores.
- Utilizar varios lenguajes de programación, como:
  - Python
  - JavaScript
  - CSS
  - HTML, etc.
- Desarrollar codigo utilizando varias herramientas integradas de git y github.

## 2. Requisitos
Para instalar Visual Studio Code se necesita:

- Una computadora con acceso a internet.
- Un sistema operativo compatble:
  - Windows: version 10 y 11 (7 y 8 limitado)
  - macOS: 10.11 o superior
  - Linux: Distribuciones principales (requiere GLIBCXX 3.4.25 y GLIB 2.28 o posteriores)
- Especificaciones de hardware minimo:
  - 1 GB de RAM
  - 500 MB de espacio en el disco
  - Procesador de 1.6 GHz o superior.
